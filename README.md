# 視覺偽人檢測 — Hue of the Fake

一款以「視網膜色彩檢測中心」為舞台的短篇心理恐怖網頁遊戲。視力測驗不是包裝，而是辨認異常、維持記憶的主要工具：玩家從色板與視力表出發，逐步比對人像、日常物件與被覆寫的檔案。

## 這次調整

- **以視力測驗為敘事核心**：色板、色相排序、視力表、熟悉影像回放，逐步構成辨認人的「色彩指紋」。
- **記憶差異檔案**：用「第一張色板明明是 74，封存紀錄卻改成 71」引入似曾相識卻無法證明的錯位；玩家再比對 5 組人像與物件的正常／異常版本。
- **獨特的彩色檢測室風格**：以深青綠、紫紅與暖琥珀呈現鏡片殘像、色彩偏移與視網膜回聲，不走黑白監視器或單純 VHS 濾鏡路線。
- **恐怖感循序升高**：開場維持冷靜的醫療檢測感；中段出現互相矛盾的封存記憶；後段讓人像、氣球、小屋與視力表接連出現異常，最後才揭露替換者。
- **讓玩家參與故事**：玩家可以選擇回報或忽略可疑訊息，選擇會改變結局敘事。
- **前面做的事會累積成壓力**：錯誤答案不再只是短暫閃爍，而會推高「異常訊號」；色彩校準與記憶比對表現會影響最終判定。即使前段失誤，仍能走完整段故事。
- **最終辨識更有份量**：名單順序每局都會打亂，提交後不能更改；正確辨識仍可能導向不同結局。
- **更方便遊玩**：新增可關閉環境音與閃爍的選項、鍵盤可操作按鈕、手機版版面與可捲動畫面。
- **GitHub Pages 相容**：不需要框架、建置程序或伺服器，全部使用相對路徑的靜態檔案。

## 遊玩

直接以瀏覽器開啟 `index.html`，或透過 GitHub Pages 網址遊玩。選擇環境音時，瀏覽器會播放低音量的合成環境音；預設為關閉。

## 發佈到 GitHub Pages

此 repository 的靜態檔案位於根目錄。到 GitHub repository 的 **Settings → Pages**，將來源設定成部署 `main` 分支的根目錄；推送更新後，Pages 會自動更新網站。

## 測試說明

此作品是恐怖遊戲，不是醫療或色覺診斷工具。遊戲中的色板與視力表不具有臨床效力。
